# 소화기계 기출 퀴즈 마스터 앱 (총 37개 강좌, 1004문항 전수 탑재)

가톨릭의대 본과 소화기학 전 강좌(간질환, 췌담도 질환, 영상/병리/외과 포함 총 37개 강좌)의 최신 족보(**총 1,004문항 전수**)를 완벽히 분석하여, 2026학년도 담당 교수님 매칭 정보와 함께 스마트하게 학습할 수 있도록 제작된 반응형 퀴즈 웹 애플리케이션입니다.

---

## 📚 최근 추가된 주요 강좌 (09/17 목요일 1~4교시)
- **[09/17 목1] 췌장 낭성질환의 진단 및 예후 (이종율 교수님)** (5문항)
- **[09/17 목2] 췌장암과 췌장수술 (홍태호 교수님)** (35문항)
- **[09/17 목3] 담낭용종과 담낭암 (이상권 교수님)** (23문항)
- **[09/17 목4] 췌장염의 외과적 치료 (한재현 교수님)** (13문항)

---

## 🎯 주요 기능

1. **강좌 다중 선택 & 요일별 원클릭 필터**
   - [전체 과목 (1004제)], [화요일 전체 (147제)], [수요일 전체 (318제)], [목요일 전체 (311제)], [금요일 전체 (168제)], [월요일 전체 (60제)] 퀵 필터
   - 37개 각 강좌별 개별 선택/해제 토글 지원

2. **올해 동일 교수님 출제 문제 표시 & 전용 필터 (Professor Matching)**
   - 2026학년도 현재 해당 강좌를 담당하시는 교수님과 동일한 기출문제에 `🎯 올해 동일 교수 (OOO 교수님)` 뱃지 및 카드 하이라이트 부여
   - 출제 당시 교수님이 다른 경우 `👤 당시 XXX 교수님 → 올해 OOO 교수님` 비교 태그 제공
   - **[🎯 올해 동일 교수 기출]** 원클릭 필터로 해당 족보만 선별 학습 가능 (전체 62문항)

3. **랜덤 1문 1답 모드 (Practice)**
   - 선택된 강좌/학번의 문제를 무작위 순서로 출제 (10/20/30/전체 문항수 조절 가능)
   - 문제 풀이 즉시 실시간 정답/오답 판정
   - **공식 해설**, **선배 작성자 해설**, **AI 심층 해설**, **YAM 핵심 요약**의 4중 해설 제공
   - 연속 정답 시 콤보(🔥 스트릭) 및 축하 파티클 효과

4. **실전 모의고사 모드 (Exam)**
   - 선택된 문제들을 실제 시험처럼 한눈에 풀고 최종 제출
   - 점수 계산, 정답률, 성적표 피드백 및 각 문제별 오답/해설 상세 분석

5. **북마크 (Bookmark)**
   - 헷갈리거나 중요한 문제를 북마크(⭐)하여 언제든 모아보기 (단축키: B)

6. **스마트 키보드 단축키 지원**
   - `1` ~ `5`: 보기 선택
   - `Enter`: 정답 확인 / 다음 문제
   - `Space`: 다음 문제로 넘어가기
   - `B`: 현재 문제 북마크 토글

7. **인터페이스 & 오디오**
   - 슬릭 다크 모드 / 클린 라이트 모드 전환
   - Web Audio API 기반 정답/오답/만점 효과음 탑재 (온/오프 지원)

## 🚀 실행 방법

### 방법 1: 더블 클릭 실행 (가장 간단함)
- 폴더 내 `index.html` 파일을 더블 클릭하여 크롬이나 엣지 브라우저에서 바로 실행합니다.
- 또는 `start_app.bat` 파일을 더블 클릭합니다.

### 방법 2: 로컬 HTTP 서버로 실행 (선택 사항)
터미널에서 해당 폴더로 이동 후 아래 명령어를 입력합니다:
```bash
python -m http.server 8000
```
그 후 브라우저에서 `http://localhost:8000`으로 접속합니다.
